# Data Types

Sync uses and extends the data types from Apoli. Below are the data types that are specific to Sync or have special implementations within Sync.

## Available Data Types

| Data Type | Description |
|-----------|-------------|
| [Model Part Transformations](./model_part_transformations.md) | Defines transformations for entity model parts, including position, rotation, scale, visibility, and animation override. |

## Using Data Types in Sync

Data types in Sync are used in power types, conditions, and actions. They are registered under the `sync` namespace and can be used alongside standard Apoli data types.
