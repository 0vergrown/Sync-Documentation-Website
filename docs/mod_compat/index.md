# Mod Compatibility Types

Sync adds some Power Types, Actions, Conditions, etc. that only work if certain mods are installed.

## Available Compatibles

| Condition                                       | Description                                          |
|-------------------------------------------------|------------------------------------------------------|
| [Modify Jade Tooltip](./modify_jade_tooltip.md) | Modifies Jade tooltip rendering with custom options. |
